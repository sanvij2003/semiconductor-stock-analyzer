---
name: Finding Shell in the editor
description: A confirmed navigation path when the Tools pane does not show Shell.
---

In the editor layout shown by the user, open Shell using the **+** immediately
to the right of the **Preview** tab, rather than searching within the Tools pane.

**Why:** The Tools pane showed individual tools such as Git, not the tool search
described by the initial instructions. After several unsuccessful navigation
directions, the user confirmed the **+** beside Preview worked.

**How to apply:** When helping locate Shell, use the visible tab-add control in
this layout. If the layout changes, request a screenshot instead of repeatedly
giving generic menu or keyboard-shortcut instructions.
